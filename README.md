# FPS Menu — мод для MojoLauncher (Fabric 1.21.1)

Мод-меню с анимациями. Открывается клавишей **P** (или кнопкой «FPS меню» в меню паузы / на титульном экране).

Вкладки:
- **FPS** — пресеты (Макс. FPS 120+ / Баланс / Красота), лимит FPS (до 260 и «без лимита»), VSync, дальность прорисовки и симуляции, дальность сущностей, счётчик FPS.
- **Камера** — FOV 30–150, эффекты FOV, плавная камера, покачивание.
- **Графика** — быстро/красиво, частицы, облака, тени сущностей.
- **Меню** — цвет акцента, анимации вкл/выкл, скорость анимаций.

Прокрутка — свайпом по строкам или колесом. Слайдер двигается за нижнюю полоску строки.

## Как получить .jar

### Вариант 1: GitHub (без компьютера, ничего не ставить)
1. Создай репозиторий на GitHub, загрузи все файлы проекта (с папками `src`, `.github`).
2. Вкладка **Actions** → дождись зелёной галочки (≈3–5 мин).
3. Вкладка **Releases** → скачай `fpsmenu-1.0.0.jar` (обычный .jar, не zip).

### Вариант 2: Termux на телефоне
```
pkg install unzip
unzip FpsMenu-Fabric-1.21.1-source.zip -d fpsmenu && cd fpsmenu
bash build_termux.sh
```
Первая сборка качает ~1 ГБ и идёт долго. Готовый .jar попадёт в `/sdcard/Download`.

## Установка в MojoLauncher
1. Создай профиль **Fabric 1.21.1**.
2. В папку `mods` положи `fpsmenu-1.0.0.jar` и **Fabric API 0.116.1+1.21.1**.
3. Чтобы открывать меню с экрана: в редакторе раскладки управления добавь кнопку и назначь ей клавишу **P**.

Примечание: в ванили на P висят «Социальные взаимодействия» — мод один раз сам освобождает эту клавишу.
